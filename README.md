# Roadmap Studio V4

Roadmap Studio 是模組化的 Web Roadmap 編輯器。

## GitHub Pages

此 repository 會透過 GitHub Actions 自動部署至：

https://k1vink1vin.github.io/roadmap-studio/

## 目前結構

- `index.html`：主頁面
- `standalone-template.html`：Standalone HTML 匯出模板
- `src/main.js`：主要互動與渲染邏輯
- `src/styles.css`：UI 樣式
- `src/core/`：Project model、palette、utilities
- `.github/workflows/deploy-pages.yml`：GitHub Pages 自動部署
